# Avvisi su diritti e dipendenze

Il pacchetto ispezionato non incorpora librerie JavaScript di terzi, font scaricabili, loghi clienti, testi integrali di standard, codice Apps Script storico o documentazione operativa. L’app usa API native del browser; il piccolo writer XLSX è incluso nel codice originale.

Le quattro checklist pubblicate contengono domande originali generiche e non costituiscono checklist ufficiali di un ente o riproduzioni dei questionari operativi storici.

WordPress è una dipendenza di esecuzione per il solo plugin; non è redistribuito in questi pacchetti. Il plugin TITANIUM è separato, non è incluso e mantiene la propria licenza e i propri avvisi.

La licenza MIT non attribuisce diritti su marchi, dati, immagini o altri materiali eventualmente importati dall’utente. Mantieni questo file e LICENSE nelle distribuzioni.
